## ⚠️ 最重要的原理提醒（写进报告！）

### 为什么不能用"12V 直流电源"？

```
❌ 排插式 DC 电源适配器（220V→12V 直流）
   输出的是直流电流 —— SCT013 是交流互感器
   直流不产生磁场变化 → SCT013 输出 ≈ 0
   → 波形是平直线，50Hz 基波不存在
   → FFT分析不了 → 整个项目崩掉

✅ 隔离变压器（220V→12V 交流）
   输出的是交流电流 —— 磁场周期性变化
   SCT013 正常工作，能看到 50Hz 波形
   电压和电流有相位差 → 能算功率因数
   → 与 WHITED 数据集（交流波形）特征可比
```

> **报告写这段叫做"设计约束分析"，导师问起来能回答就赢了。**

### SCT013 的"输出"到底是什么？

SCT013-005 输出是一个 **±1V 的交流小信号**（电流互感器比例输出）：
- 5A 满量程时约 1V
- 需要调理电路把信号抬到 ESP32 ADC 可读的 0~3.3V 范围

### 接线图（10 分钟能搞定）

```
          220V 插座 ───┬── 隔离变压器 ───┬── 12V 交流输出
                       │                │
                       │          ┌─────┴─────┐
                       │          │  被测设备   │ (灯泡/风扇等)
                       │          └─────┬─────┘

                       │                  │            │
                       │          ZMPT101B─┬───────────┴─ ESP32 ADC(引脚35)
                       │                  │
                       └──────────────────┴── GND(共地)
```

## 🛠 组装步骤（30 分钟完成）

### Step 1：接交流电源线
1. 拿一根带插头的电源线
2. 剥线，接到 12V 变压器输入端（注意：220V 端用绝缘胶带包好！）
3. 万用表打到 AC 电压档，确认输出端约 12V AC

### Step 2：接 SCT013
1. SCT013 是一个"夹子"形状的互感器
2. **把被测设备的一根电源线穿过夹子中间的孔**（注意：只穿一根线，两根都穿磁场抵消）
3. SCT013 输出的两头（红色/黑色线）接到调理电路

### Step 3：搭调理电路
```
SCT013(红) ──┬── R1(10kΩ) ──┬── ESP32 ADC(引脚34)
             │               │
            +3.3V          C1(10µF)
             │               │
             └── GND ────────┘

原理（用初中物理讲）：
- 10kΩ/10kΩ 分压 → 把 ±1V 信号往上抬，让中心到 1.65V
- 10µF 电容 → 隔直流，防止偏置电压影响
```

### Step 4：接 ZMPT101B
1. ZMPT101B 模块有三个引脚：VCC(3.3V)、GND、OUT
2. 直接把模块插到面包板，VCC 接 ESP32 3.3V，GND 接地，OUT 接 ADC(引脚35)
3. 电压探头接在 12V 输出端两侧

### Step 5：上电
1. **先不要插测试设备**，只上电，确认 ESP32 串口能输出"噪声"波形
2. 插上灯泡，确认能看到 50Hz 正弦波
3. 如果波形是平的 → 检查 SCT013 是否只穿了一根线

## 💡 如果出问题（对症下药）

| 症状 | 原因 | 解决 |
|------|------|------|
| 波形是平的 | 12V 直流供电 OR SCT013 两根线都穿了 | 换交流变压器 / 只穿一根线 |
| 波形太乱全是噪声 | 采样率太低 / 地线没接好 | 提高采样率到 4kHz / 检查共地 |
| 波形有巨大尖刺 | 启动电流 | 取中段稳定数据 |
| 输出一直满量程 | SCT013 装反或量程太小 | 检查量程，换 5A |
| 笔记本电源带不起 | 变压器功率不够 | 选 30W 以上 |
