## 为什么需要模拟数据

1. **开发阶段**：代码先行，不用等硬件到货
2. **调试阶段**：如果代码跑通了但准确率低，说明特征提取有问题（不是硬件问题）
3. **演示备份**：万一上课时硬件出问题，可以用模拟数据演示算法流程

## 模拟数据的生成规则

我们模拟 5 种电器在 220V 电网下的电流波形：

| 电器 | 功率 | 电流均值 | 谐波特征 |
|------|:---:|:---:|---------|
| 白炽灯 | 60W | 0.27A@220V | 纯电阻，几乎无谐波 |
| LED灯 | 8W | 0.036A | 开关电源，3谐波高 |
| 风扇 | 30W | 0.14A | 电机，2谐波略高 |
| 手机充电器 | 10W | 0.045A | 谐波极丰富 |
| 笔记本充电 | 65W | 0.3A | 谐波中等 |

简化后按 12V 测试电压换算：`I_12V = P / 12V`

```python
# simulate_data.py
import numpy as np
import pandas as pd

def generate_wave(kind, duration_sec=1.0, sample_rate=2000,
                  noise=0.01, freq_jitter=0.2):
    """
    模拟某个电器的电流波形。
    
    数学原理：
    电流(i) = 基波(i1·sin) + 谐波(i3·sin3) + 高次谐波 + 噪声
    """
    n = int(duration_sec * sample_rate)
    t = np.arange(n) / sample_rate
    f_base = 50.0 + freq_jitter * np.random.randn()  # 50Hz 稍有波动

    # 每种电器的"签名"（基波幅值 + 各谐波比例）
    signatures = {
        'bulb':        {'P': 10,  'h': [1.0, 0.01, 0.005, 0.001]},
        'led':         {'P': 3,   'h': [1.0, 0.35, 0.15, 0.05]},
        'fan':         {'P': 5,   'h': [1.0, 0.20, 0.10, 0.03]},
        'phone_charger': {'P': 2, 'h': [1.0, 0.45, 0.20, 0.08]},
        'laptop':      {'P': 12,  'h': [1.0, 0.40, 0.15, 0.05]},
        'empty':       {'P': 0,   'h': [0.0, 0.0, 0.0, 0.0]},
    }

    P, harmonics = signatures[kind]

    # 电流幅值 = P / V  (V=12V 测试电压)
    i_base = P / 12.0

    wave = np.zeros(n)
    for idx, amp in enumerate(harmonics):
        fk = f_base * (idx + 1)  # 第 idx+1 次谐波频率
        wave += i_base * amp * np.sin(2*np.pi*fk*t + np.random.rand()*2*np.pi)

    # 加白噪声 + 硬件偏置
    wave += noise * np.random.randn(n)
    wave += 0.02  # 模拟 ADC 偏置

    return wave


def generate_all_data(output_file="simulated_data.csv",
                      secs_per_device=2.0, num_per_device=10):
    """生成 5 种设备 × 10 段 模拟数据"""
    kinds = ['bulb', 'led', 'fan', 'phone_charger', 'laptop', 'empty']
    rows = []
    rec_id = 0

    for kind in kinds:
        for rep in range(num_per_device):
            wave = generate_wave(kind, duration_sec=secs_per_device)
            # 每个采样点一行
            for i, val in enumerate(wave):
                rows.append([rec_id, i / 2000.0, val, kind])
            rec_id += 1

    df = pd.DataFrame(rows, columns=['recording_id', 'timestamp',
                                     'current', 'label'])
    df.to_csv(output_file, index=False)
    print(f"已生成 {len(df)} 行模拟数据 → {output_file}")
    return df


if __name__ == "__main__":
    generate_all_data()
```

## 如何用模拟数据跑完整流程

1. 运行 `simulate_data.py` 生成 `simulated_data.csv`
2. 用 06 教程里的特征提取代码（`extract_features.py`）处理模拟数据
3. 用 04 教程里的训练代码（`train_model.py`）训练模型

模拟数据期望准确率：**随时无噪声/低噪声时应该接近 100%**。
如果模拟数据都准确率很低，说明代码有 bug，先修代码再看硬件。

## 模拟数据的局限（写报告时诚实说明）

| 差距 | 模拟 | 真实 |
|------|------|------|
| 噪声 | 高斯白噪声 | 电网谐波、电磁干扰、传感器噪声 |
| 频率 | 固定 50Hz±0.2 | 波动 ±1Hz |
| 谐波模式 | 理想谐波组合 | 每个电器有独特但时变谐波 |
| 瞬态 | 无 | 开/关瞬间有尖峰 |

> **诚实是学术美德**：报告中明确"模拟数据用于调试流程图，最终结论基于 12V 实测 / WHITED 验证"。
