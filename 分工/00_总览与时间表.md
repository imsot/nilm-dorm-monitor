## 🧭 核心变化（和旧版最大的区别）

| 旧方案 ❌ | 新方案 ✅ |
|-----------|-----------|
| 220V→**12V直流**适配器 | 220V→**12V交流**安全变压器 |
| SCT013 读直流 → 波形是平直线 ❌ | SCT013 读交流 → 50Hz基波 + 谐波真实存在 ✅ |
| 没有 50Hz 基波，FFT分析不了 | 电压电流都有相位，能算功率因数 |

> 一句话总结新版原理：**用一只 220V→12V 的"交流变压器"给测试设备供电，SCT013 电流互感器和 ZMPT101B 电压互感器都工作在正常状态，50Hz 基波和谐波真实可见。**

## 🗣️ 大白话版：整个项目一句话讲清楚

### 我们的项目是干嘛的？

> **给宿舍插座装一个"耳朵"，听出哪个电器在用电。**

就像你听脚步声能认出是谁走来，我们听电流的"声音"能认出哪台电器在工作（灯、风扇、充电器、笔记本……）。

### 整个流程一共 5 步（用大白话说）

```
① 买东西      → 花 ¥133 买：ESP32板 + 电流夹子(SCT013) + 电压模块 + 一堆线
② 接电路      → 把夹子夹住电线，把线接到 ESP32 上（照图接，半小时搞定）
③ 收数据      → ESP32 每秒采样4000次，录下电流波形 → 存成CSV文件
④ 找特点      → 用"FFT"把波形拆开看：3谐波多少？5谐波多少？→ 每个电器得到一串特征数字
⑤ 认电器      → 用 sklearn 训练一个"猜电器"的程序，给它新波形它能猜出来
```

### "三条证据链"是什么鬼？用大白话说

导师要求不是"你说是就是"，要有三个证明来源：

| 证据链 | 大白话说 |
|--------|---------|
| ① 自己做的 12V 实验台 | 我们亲手搭的、在台上演示 |
| ② 220V 真实场景验证 | 用真电源验证一次（导师监督下） |
| ③ WHITED 公开数据集 | 拿世界上别人录的数据，证明算法不是只在我们的实验室管用 |

**三个都做到 → "这个检测器是真的能在真实世界用的"**
