## 📐 原理：FFT到底是什么（用你会的数学讲）

### 前置知识：内积（点积）

你学过向量内积：

```
向量 a = (a1, a2, a3), 向量 b = (b1, b2, b3)

a·b = a1·b1 + a2·b2 + a3·b3
```

**直觉**：内积大 = 两个向量方向越接近。

### 类比：内积 = "这个信号和这个频率有多像"

想象信号是一个"复杂的声音"，正弦波是"一个纯净的音"。

**信号里有没有 150Hz 这个音？**

很简单：把信号和 `sin(2π·150·t)` 做"内积"：
- 如果信号里确实有 150Hz 成分 → 内积很大（方向接近）
- 如果没有 → 内积很小（方向几乎垂直）

### 数学公式（高数上册够用）

给信号 x[n]（下面 n 从 0 到 N-1），想求它在频率 fk 的幅值：

```
A_k = (2/N) * Σ_{n=0}^{N-1} x[n] * cos(2π * k * f0 * n * Ts)
B_k = (2/N) * Σ_{n=0}^{N-1} x[n] * sin(2π * k * f0 * n * Ts)

幅值_k = sqrt(A_k² + B_k²)
```

其中：
- `f0` = 电网频率（在中国是 50Hz）
- `N` = 采样点数
- `Ts` = 采样周期 = 1/采样率
- `k` = 谐波次数（k=1 是基波，k=3 是三次谐波）

### ⚠️ 特别提醒：这不是 FFT！

FFT 会一次性算出**所有**频率的幅值，但需要处理窗函数、频谱泄漏等复杂问题。

**FFT只算我们关心的几个频率点**（50Hz、150Hz、250Hz、350Hz），一次内积算一个，简单直接，数学清晰。

这段话来自旧版错误的描述，现已被修正：FFT 是一种成熟算法，我们直接调用库函数，不需要自己实现。

## 🐍 完整代码

### 第一步：找电网真实频率（测 48~52Hz）

电网频率其实不是准确的 50Hz，可能有 ±0.3Hz 偏差。为了精确提取谐波，我们需要先测出真实频率。

```python
# find_fundamental.py
import numpy as np

def find_fundamental_frequency(signal, sample_rate=2000,
                               f_min=45.0, f_max=55.0, step=0.05):
    """
    扫描 45~55Hz，找基波频率。

    原理：对每个候选频率 f，算信号与 cos(2πf·t) 的内积
          内积平方最大 = 信号在该频率分量最强 = 基波频率

    参数：
        signal : 一维波形数组
        sample_rate : 采样率 Hz
        f_min, f_max : 扫描范围
        step : 扫描粒度

    返回：
        最佳基波频率 f0
    """
    n = len(signal)
    t = np.arange(n) / sample_rate

    best_f = 50.0   # 默认值
    best_energy = 0.0

    for f in np.arange(f_min, f_max + step, step):
        # 内积（就是求和）
        cos_product = np.sum(signal * np.cos(2 * np.pi * f * t))
        sin_product = np.sum(signal * np.sin(2 * np.pi * f * t))
        energy = cos_product**2 + sin_product**2

        if energy > best_energy:
            best_energy = energy
            best_f = f

    return best_f
```

### 第二步：特征提取（核心函数）

```python
# extract_features.py
import numpy as np
import pandas as pd
import os

def extract_features(signal, f0, sample_rate=2000, max_harmonic=7):
    """
    用FFT提取谐波特征。

    输入:
        signal   : 一维波形（已去偏置）
        f0       : 基波频率（用于精确匹配谐波频率）
        sample_rate : 采样率
        max_harmonic: 提取到第几次谐波

    返回:
        feature dict: RMS、基波幅值、各次谐波幅值、THD、Crest
    """
    n = len(signal)
    t = np.arange(n) / sample_rate

    # 时域特征
    rms = np.sqrt(np.mean(signal**2))

    # 频域：FFT提取各次谐波
    harmonics = []
    for k in range(1, max_harmonic + 1):
        fk = k * f0  # 第k次谐波频率
        cos_mask = np.cos(2 * np.pi * fk * t)
        sin_mask = np.sin(2 * np.pi * fk * t)

        A_k = (2.0 / n) * np.sum(signal * cos_mask)
        B_k = (2.0 / n) * np.sum(signal * sin_mask)
        amp_k = np.sqrt(A_k**2 + B_k**2)

        harmonics.append(amp_k)

    harmonics = np.array(harmonics)

    # 归一化：各次谐波除以基波（消除电压波动影响）
    # 如果基波接近0（空载），就除以一个极小数防止除零
    base = max(harmonics[0], 1e-6)
    harmonics_norm = harmonics / base

    # 总谐波畸变率 THD = sqrt(Σ_{k>=2}(Hk/H1)^2)
    thd = np.sqrt(np.sum(harmonics_norm[1:] ** 2))

    # 峰值因子（Crest factor）= 峰值/RMS
    crest = np.max(np.abs(signal)) / max(rms, 1e-6)

    # 差波（波形与纯基波之差）的特征
    # 用FFT重建纯基波
    pure_base = (harmonics[0] * np.sin(2*np.pi*f0*t + np.angle(
        np.sum(signal * np.exp(1j*2*np.pi*f0*t)) by 用 angle 的方式 / np.abs(...)
    )))

    feature = {
        'rms': rms,
        'h1': harmonics_norm[0],   # 基波（归一化后=1）
        'h2': harmonics_norm[1],
        'h3': harmonics_norm[2],
        'h4': harmonics_norm[3],
        'h5': harmonics_norm[4],
        'h6': harmonics_norm[5],
        'h7': harmonics_norm[6],
        'thd': thd,
        'crest': crest,
    }
    return feature
```

### 第三步：批量处理所有 CSV

```python
# batch_extract.py
import numpy as np
import pandas as pd
import glob

def process_all_csv(data_dir, sample_rate=2000):
    """批量处理 B 同学录制的所有 CSV 文件，生成特征表"""
    all_features = []

    for csv_file in sorted(glob.glob(f"{data_dir}/*.csv")):
        df = pd.read_csv(csv_file)
        signal = df['current'].values

        # 1. 去直流偏置：减去均值
        signal = signal - np.mean(signal)

        # 2. 取中间稳定段（去掉开头和结尾的切换瞬态）
        start = len(signal) // 4
        end   = len(signal) * 3 // 4
        stable = signal[start:end]

        # 3. 找基波频率
        f0 = find_fundamental_frequency(stable, sample_rate)

        # 4. 提取特征
        feat = extract_features(stable, f0, sample_rate)
        feat['label'] = df['label'].iloc[0]
        feat['recording_id'] = df['recording_id'].iloc[0]

        all_features.append(feat)

    result = pd.DataFrame(all_features)
    result.to_csv('features.csv', index=False)
    print(f"特征表已保存: {result.shape[0]} 段 × {result.shape[1]} 列")

    return result
```

import matplotlib.pyplot as plt
import pandas as pd

# 画时域波形
def plot_waveform(csv_file, save='waveform.png'):
    df = pd.read_csv(csv_file)
    signal = df['current'].values
    t = np.arange(len(signal)) / 2000.0

## 💡 如果特征不够区分怎么办

先看这张表：

| 特征 | 区分什么设备 |
|------|------------|
| RMS | 功率大小 |
| THD | 开关电源 vs 电阻负载 |
| H3/H1 | 电机（风扇）特有 |
| H5/H1 | 充电器特有 |
| Crest factor | LED 驱动特有 |

如果某两类设备分不开，回到 B 那边看波形，可能是采样问题不是算法问题。
