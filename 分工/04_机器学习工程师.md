## ⚠️ 第一条铁律：数据划分方式

**不能直接用 `train_test_split(X, y)` 随机分！**

原因：同一录制段内相邻波形几乎一模一样，如果同一段的一部分进了训练集、一部分进了测试集，模型等于"背答案"，准确率虚高到 99%。

正确做法：**按 recording_id 分组划分**。

```python
from sklearn.model_selection import GroupShuffleSplit

splitter = GroupShuffleSplit(n_splits=1, test_size=0.3, random_state=42)
train_idx, test_idx = next(splitter.split(X, y, groups=rec_ids))

X_train, X_test = X[train_idx], X[test_idx]
y_train, y_test = y[train_idx], y[test_idx]
```

## 🚀 完整训练代码

```python
# train_model.py
import numpy as np
import pandas as pd
from sklearn.model_selection import GroupShuffleSplit, cross_val_score, GridSearchCV
from sklearn.tree import DecisionTreeClassifier
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix
import matplotlib.pyplot as plt

# =========================================
# 1. 加载特征表
# =========================================
df = pd.read_csv('features.csv')

feature_cols = ['rms', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6', 'h7', 'thd', 'crest']
X = df[feature_cols].values
y = df['label'].values
rec_ids = df['recording_id'].values

# =========================================
# 2. 按录制段划分
# =========================================
splitter = GroupShuffleSplit(n_splits=1, test_size=0.3, random_state=42)
train_idx, test_idx = next(splitter.split(X, y, groups=rec_ids))

# =========================================
# 3. 特征标准化（把单位不同的特征统一尺度）
# =========================================
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X[train_idx])
X_test_scaled = scaler.transform(X[test_idx])

# =========================================
# 4. 训练决策树
# =========================================
clf = DecisionTreeClassifier(
    max_depth=4,        # 限制深度，防止过拟合
    min_samples_split=3,
    random_state=42
)
clf.fit(X_train_scaled, y[train_idx])

# =========================================
# 5. 评估
# =========================================
y_pred = clf.predict(X_test_scaled)
acc = accuracy_score(y[test_idx], y_pred)
print(f"决策树测试集准确率: {acc:.4f}")
print(f"训练集准确率: {clf.score(X_train_scaled, y[train_idx]):.4f}")

# =========================================
# 6. 混淆矩阵
# =========================================
cm = confusion_matrix(y[test_idx], y_pred, labels=sorted(set(y)))

fig, ax = plt.subplots(figsize=(6, 5))
im = ax.imshow(cm, cmap='Blues')
ax.set_xticks(range(len(sorted(set(y)))))
ax.set_yticks(range(len(sorted(set(y)))))
ax.set_xticklabels(sorted(set(y)))
ax.set_yticklabels(sorted(set(y)))

# 在格子中显示数字
for i in range(cm.shape[0]):
    for j in range(cm.shape[1]):
        ax.text(j, i, cm[i, j], ha='center', va='center', color='white' if cm[i,j] > cm.max()/2 else 'black')

ax.set_xlabel('预测标签')
ax.set_ylabel('真实标签')
ax.set_title('混淆矩阵')
plt.tight_layout()
plt.savefig('confusion_matrix.png', dpi=150)
print("混淆矩阵已保存 → confusion_matrix.png")

# =========================================
# 7. 对照实验：kNN
# =========================================
knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train_scaled, y[train_idx])
knn_acc = accuracy_score(y[test_idx], knn.predict(X_test_scaled))
print(f"kNN 测试集准确率: {knn_acc:.4f}")

# 选准确率高的作为最终模型
best_model = clf if acc >= knn_acc else knn
print(f"最终模型: {'决策树' if best_model is clf else 'kNN'}")

# =========================================
# 8. 特征重要性（决策树自带）
# =========================================
if best_model is clf:
    print("\n特征重要性:")
    for name, imp in zip(feature_cols, clf.feature_importances_):
        print(f"  {name:8s}: {imp:.3f}")
```

## 🧠 初学者问答（答辩前背下来）

**Q: 为什么用决策树？**
A: 决策树规则透明，可以画出判断条件（如"如果 H3/H1 > 0.5 就是风扇"），可解释性强，适合教学展示。相比神经网络黑盒，决策树更适合这个项目"讲清楚原理"的目标。

**Q: 为什么 max_depth=4?**
A: 深度太大 → 模型记住训练集每个细节 → 过拟合。深度 4 保持"够用且不死板"。"**过拟合**"这个概念答辩必问，提前背好定义：模型在训练数据上表现很好，但新数据上很差，因为它学了噪音而不是规律。

**Q: 准确率 90% 够吗？**
A: 对这个教学项目够。更重要的是找差距——哪些设备容易混，为什么混？比如 LED 灯和充电器开关频率接近，可能就是混淆的原因。
