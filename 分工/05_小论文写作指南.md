# 📝 05 - 小论文写作指南（10周版，助理写作）

> **目标：完成一篇 8000~10000 字的课程小论文，按期刊论文格式排版**

---

## 一、论文结构（对应报告模板）

| 章节 | 字数 | 内容重点 |
|------|:---:|---------|
| 摘要 | 300 | 做了什么、怎么做的、结果如何 |
| 关键词 | 4-6个 | 非侵入式负载识别；NILM；机器学习；谐波 |
| 1 项目背景及目标 | 1000 | 为什么做、现状痛点、目标 |
| 2 团队和项目管理 | 800 | 甘特图 + 分工表 + 预算 |
| 3 客户需求评估 | 1500 | 问卷设计 + 数据图表 + 需求分析 |
| 4 同类产品分析 | 1500 | 3+个产品对比 + 专利分析 |
| 5 技术方案 | 2000 | 硬件架构 + 特征提取 + 机器学习 |
| 6 测试与结果 | 1500 | 测试记录表 + 准确率 + 混淆矩阵 |
| 7 结论与展望 | 800 | 总结、局限、改进方向 |

---

## 二、写作时间线

| 周次 | 写作任务 |
|:---:|---------|
| W1 | 写需求分析草稿（问卷数据出来后） |
| W3 | 写产品分析草稿（4个产品对比表） |
| W5 | 写技术方案草稿（算法是有，但文字还没写） |
| W6 | 写测试结果草稿（依赖C、D数据） |
| W7 | 整合全文初稿 |
| W8 | 排版 + 图表制作 |
| W9 | 打磨语言 + 加参考文献 |

## 三、写作技巧（每个章节怎么写）

### 摘要模板（直接填）

```
针对[痛点]，本课题设计并实现了一个[项目名]。系统采用[硬件方案]，
通过[特征提取方法]提取电器的谐波特征，并使用[机器学习算法]实现了
对[多少种]常见宿舍电器的非侵入式识别。实验结果表明，在[数据集]上，
系统达到了 [XX]% 的分类准确率，验证了该方案在[应用场景]下的可行性。
```

### "3 客户需求评估"怎么写

用问卷数据图表说话：

1. 问卷设计（6题，截图放进附录）
2. 回收数据（柱状图：超支比例）
3. 需求归类（转成工程需求 → 功能需求 + 非功能需求）
4. 结论：最需要什么

### "5 技术方案"怎么写（重点）

| 小节 | 内容 |
|------|------|
| 5.1 系统架构 | 框图：AC12V → 调理 → ESP32 → 串口 → PC |
| 5.2 硬件设计 | 元件型号 + 电气参数 + 原理图 |
| 5.3 特征提取 | FFT公式 + 为什么选它 |
| 5.4 机器学习 | 数据集划分方式 + 模型选择 + 超参数 |

## 四、参考文献引用技巧

至少要引用：

1. **Hart 1992**（NILM 奠基论文）
2. ZMCT103C datasheet（硬件）
3. 一部 sklearn 文档或教材（机器学习）
4. 一篇中文综述性的 NILM 文章

格式按"GB/T 7714"（中文期刊常用）：
```
[1] Hart G W. Nonintrusive appliance load monitoring[J].
    Proceedings of the IEEE, 1992, 80(12): 1235-1253.
```

## 五、"AI使用说明"怎么写（模板要求）

> 本课题使用了 AI 生成的代码框架和文档草稿（具体写明用了哪些AI、做了什么、有没有检查）。

范例：
```
本小组在以下环节使用了AI工具：
1. 使用大模型生成初始的 ESP32 采样代码框架，人工检查后使用
2. 使用大模型生成特征提取函数的初稿，手工验证逻辑
3. AI辅助论文排版和润色
以上AI生成内容均经过小组人工验证，结果数据全部来自真实实验。
```
